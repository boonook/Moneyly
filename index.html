Moneyly User Help & Support

Thank you for using Moneyly! This document will help you get started quickly and answer common questions you may encounter.

1. App Overview

Moneyly is a simple and easy-to-use personal expense tracker that helps you record every income and expense and stay on top of your finances.

Key features:

  • 📝 Record Transactions: Quickly log income/expenses with categories, notes, and receipt photos
  • 📊 Statistics & Reports: View income and expenses by today / this week / this month / this quarter / this year to see where your money goes
  • 💰 Budget Management: Set a monthly budget and track your remaining balance in real time
  • 🔒 Security: 6-digit passcode + Face ID / fingerprint unlock
  • 🌍 Multilingual: Supports Chinese (Simplified / Traditional) and English

2. Getting Started

  1. Open the app. On first launch, a local account is created automatically (nickname defaults to Moneyly)
  2. Tap Home in the bottom navigation to see today's and this month's income and expense overview
  3. Tap the Add Transaction button, enter the amount, choose the type (income/expense) and category, then save
  4. After recording, the Home, Transactions, and Statistics pages update automatically

3. Feature Guide

3.1 Recording a Transaction

  • Enter the amount (required)
  • Select the type: Income or Expense
  • Select a category, e.g., Dining, Transportation, Shopping, Salary, etc.
  • Optionally add a note for easy reference later
  • Optionally attach a receipt image (choose from photo library or take a photo)

3.2 Transactions

  • Transactions are grouped by date, showing daily income/expense totals
  • Tap any transaction to view its details
  • Transactions can be edited or deleted

3.3 Statistics

  • Switch time ranges: Today / This Week / This Month / This Quarter / This Year
  • Budget Remaining: Shows budget usage for the current time range
  • Income & Expense Summary: View total income and total expenses for the selected period
  • Smart Insights: Spending change compared to last month, and the highest-spending day this month
  • Trends: Daily average income/expenses and trend charts
  • Category Breakdown: Spending amount and share for each category
  • Monthly Comparison: Bar chart comparing income/expenses over the last four months

3.4 Budget Settings

  • Go to Budget Settings to adjust your monthly budget
  • The default budget is ¥3,000 and can be changed at any time
  • The Home page shows this month's spending, remaining balance, and a progress bar to help you control your spending

3.5 Security Lock (Passcode + Biometrics)

  • Set Passcode: Set a 6-digit passcode the first time you enter Security Settings
  • Change Passcode: After setting a passcode, you can change it in Settings
  • Face ID / Fingerprint: After enabling it in system settings, use biometrics for quick unlock (your device must have Face ID / fingerprint enrolled)

3.6 Profile

  • In Me / Settings, you can:
    • Change your nickname (up to 10 characters)
    • Change your avatar (choose from built-in avatars or your photo library; images are auto-cropped and must be under 1 MB)
    • View app version information

4. Frequently Asked Questions (FAQ)

Q1: Where is my data stored? Will I lose it?

All your transactions, settings, and other data are stored locally on your device (in the app's private database) and are never uploaded to a server. Uninstalling the app or clearing its data will result in data loss. We recommend regularly exporting/backing up important data (if needed, let us know via the contact details at the bottom — we are planning a cloud backup feature).

Q2: What if I forget my passcode?
  • If you have Face ID / fingerprint enabled, unlock with biometrics and change the passcode in Settings.
  • If you forgot the passcode and biometrics is not enabled, you will currently need to reinstall the app to get in (local data will be cleared as well).
  • We recommend enabling biometrics right after setting a passcode to avoid this inconvenience.
Q3: Face ID / fingerprint doesn't work?

Check the following in order:

  1. Face ID / fingerprint is enrolled in your device's system settings (Settings → Face ID & Passcode / Fingerprint)
  2. Biometric unlock is enabled in Moneyly's Settings → Security
  3. The system has not disabled biometric access for the app
Q4: Why can't I pick or save images from my photo library?

The first time you use photo library features, the system will ask for permission — please choose Allow. If you previously chose "Don't Allow":

  • iOS: Go to Settings → Privacy → Photos and allow Moneyly to access your photos
  • Android: Go to Settings → Apps → Moneyly → Permissions and enable storage/photo permissions
Q5: Why don't the amounts and statistics add up?
  • Make sure the type (income/expense) and category are correct when recording
  • Statistics are calculated for the selected time range by default; numbers will differ when you switch ranges (today/this week/this month…)
  • Budget remaining is based on the monthly budget — check it in Budget Settings
Q6: The app is slow or laggy. What can I do?
  1. Close other background apps to free up memory
  2. Free up storage space on your device
  3. Restart the app; if the issue persists, try restarting your phone
  4. Make sure the app is updated to the latest version
Q7: Can I sync across multiple devices?

Multi-device cloud sync is not supported yet — data is stored only on the current device. Cloud sync is on our roadmap, so stay tuned!

Q8: How do I report issues or suggest features?

See Contact Us below. Please include as much of the following as possible:

  • Phone model and OS version
  • App version (Settings → About)
  • Steps to reproduce the issue and screenshots
