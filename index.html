Moneyly 用户帮助与支持

感谢使用 Moneyly！本文档将帮助你快速上手，并解答使用过程中常见的问题。

一、应用简介

Moneyly 是一款简单好用的个人记账应用，帮助你随时记录每一笔收入和支出，掌握自己的财务状况。

主要功能：

  • 📝 记账：快速记录收入/支出，支持分类、备注、添加收据图片
  • 📊 统计报表：按今天/本周/本月/本季度/本年查看收支情况，了解钱花在了哪里
  • 💰 预算管理：设置每月预算，实时掌握剩余可用金额
  • 🔒 安全保护：支持 6 位数字密码 + 面容 ID / 指纹解锁
  • 🌍 多语言：支持中文（简体/繁体）与英文

二、快速上手

  1. 打开应用，首次进入会自动创建一个本地账户（昵称默认为 Moneyly）
  2. 点击底部导航进入「首页」，首页会展示今日与本月收支概况
  3. 点击「记账」按钮，输入金额、选择类型（收入/支出）与分类，保存即可
  4. 记账完成后，首页、账单页、统计页会自动更新数据

三、功能使用指南

1. 记账（添加一笔收支）

  • 输入金额（必填）
  • 选择类型：收入 或 支出
  • 选择分类：如餐饮、交通、购物、工资等
  • 可填写备注，方便日后查找
  • 可添加收据/凭证图片（从相册选择或拍照）

2. 账单

  • 账单按日期分组展示，可查看每天的收支合计
  • 点击任意一笔账单可查看交易详情
  • 支持修改和删除账单

3. 统计

  • 切换时间范围：今天 / 本周 / 本月 / 本季度 / 本年
  • 预算剩余：展示当前时间范围内的预算使用情况
  • 收入支出汇总：查看选中时间段内的总收入与总支出
  • 智能分析：本月相比上个月的支出变化、本月支出最高的一天
  • 收支趋势：日均收支与趋势图
  • 分类占比：每个分类的支出金额与占比
  • 月度对比：近四个月收入/支出柱状图对比

4. 预算设置

  • 进入「设置预算」页面可调整每月预算金额
  • 默认预算为 3000 元，随时可以修改
  • 首页会展示本月已支出、剩余可用及进度条，帮助控制消费

5. 安全锁（密码 + 生物识别）

  • 设置密码：首次进入安全设置时，设置 6 位数字密码
  • 修改密码：已设置密码后，可在设置中修改
  • 面容 ID / 指纹：在系统设置中开启后，可用生物识别快速解锁（需要手机本身已录入面容/指纹）

6. 个人资料

  • 在「我的 / 设置」中可以：
    • 修改昵称（最长 10 个字符）
    • 更换头像（内置多款头像，或从相册选择，会自动裁剪，图片不超过 1MB）
    • 查看应用版本信息

四、常见问题（FAQ）

Q1：我的数据存在哪里？会丢失吗？

你的所有账单、设置等数据都保存在手机本地（应用私有数据库中），不会上传到服务器，卸载应用或清除应用数据会导致数据丢失。建议定期导出/备份重要数据（如有需要请通过文末联系方式反馈，我们正在规划云备份功能）。

Q2：忘记密码怎么办？
  • 如果你开启了面容 ID / 指纹，可以直接用生物识别解锁，然后到设置中修改密码。
  • 如果既忘记密码、又没开启生物识别，目前需要重新安装应用才能进入（本地数据会一并清除）。
  • 建议设置密码后立即开启生物识别，避免忘记密码带来的不便。
Q3：面容 ID / 指纹用不了？

请依次检查：

  1. 手机系统设置中已录入面容/指纹（系统「设置 → 面容 ID 与密码 / 指纹」）
  2. Moneyly 的「设置 → 安全」中已开启生物识别开关
  3. 系统未禁用该应用的生物识别权限
Q4：为什么不能从相册选图 / 保存图片？

首次使用相册相关功能时，系统会弹出权限申请，请选择允许。若之前点了「不允许」：

  • iOS：进入系统「设置 → 隐私 → 照片」，允许 Moneyly 访问
  • Android：进入系统「设置 → 应用 → Moneyly → 权限」，开启存储/照片权限
Q5：为什么金额、统计数字对不上？
  • 请确认记账时选择的类型（收入/支出）和分类是否正确
  • 统计页默认按所选时间范围统计，切换范围（今天/本周/本月…）数字会不同
  • 预算剩余按本月预算计算，可在设置预算中查看
Q6：应用打开很慢 / 卡顿怎么办？
  1. 关闭后台其他应用，释放手机内存
  2. 清理手机存储空间
  3. 重启应用；如仍异常，尝试重启手机
  4. 确认应用已更新到最新版本
Q7：可以多设备同步吗？

目前暂不支持多设备云同步，数据仅保存在当前设备。云同步功能正在规划中，敬请期待。
